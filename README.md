# AI-Helper Product Descriptions

Прототип сервиса для B2B интернет-магазина, который по техническим данным контрольно-измерительного прибора создает черновик карточки товара с использованием LLM API (через OpenRouter).

## Архитектурные решения

1. **Отказ от тяжелых фреймворков (LangChain):** Для реализации использован чистый Python и официальный SDK OpenAI, настроенный на работу с OpenRouter. Это обеспечивает максимальную прозрачность кода, высокую скорость работы и отсутствие скрытой магии.
2. **Валидация данных (Pydantic):** Все входные и выходные данные валидируются через строгие схемы `BaseModel`, что гарантирует защиту от битого JSON, отсутствующих полей и несоответствия структуры ответа от LLM.
3. **Защита от галлюцинаций:** Температура генерации установлена в `0.0`. В системном промпте заданы жесткие ограничения: запрещено выдумывать технические характеристики, числовые диапазоны и параметры. При отсутствии данных требуется указывать "данных нет".
4. **Интерфейс (Streamlit):** Разработан интерактивный веб-интерфейс для выбора демо-товаров из YML-фида или ручного ввода JSON, с возможностью копирования готовых блоков в один клик.

## Используемые промпты

Системный промпт задает роль опытного SEO-специалиста и контент-менеджера B2B интернет-магазина. Модель обязана вернуть ответ строго в формате JSON со следующими ключами:
- `seo_title`: SEO-заголовок (строго до 70 символов).
- `seo_description`: SEO-описание (от 800 до 1200 символов).
- `key_specs`: Список ключевых характеристик.
- `search_queries`: 3-5 поисковых запросов для SEO.
- `commercial_block`: Коммерческий блок для менеджера (целевая аудитория и решаемые задачи).
